# SoundSwap

Switch your Windows microphone and headset (or speakers) with one keyboard shortcut.
SoundSwap is free and open source ([MIT](https://github.com/Stevehunn/soundswap/blob/main/LICENSE)).

- [Releasing](articles/releasing.md): how to publish a version.
- [API reference](api/index.md): every public type and member.
